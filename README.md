Small Project for a budget website where the user will be able to calculate their expenses, get a report and get reactions for a sec character.
Practicing backend building api for a budget app/website, while doing a small frontend with JS
Eventually both front and backend will be able to communicate with each other.
For now am doing it separately to be able to practice both separately and later merge them together.

Instructions: 
To launch FastAPI run in /budget_buddy : 
        uvicorn backend:app --reloa
        open port it is live in and add /docs at end to test API's

To launch frontend with FastAPI change line 68 in index.html to
          <script src="script-backend.js"></script>
          left click sccript-backend.js in VS-Code "Open with Live Server"
